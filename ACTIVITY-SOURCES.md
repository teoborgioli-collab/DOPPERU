# Guide activity sources

Activity ideas paraphrased from the user-supplied German Lonely Planet Peru PDF.
The PDF itself is not included in this app — every entry only ever stores a
page number, never the guidebook's own text, and the description in the app
is an independently written one-sentence summary of the underlying fact, not
a translation of guidebook prose. Prices, opening hours and booking
availability have not been verified — check the guidebook or current sources
before booking anything.
